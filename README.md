# Commercial Kitchen Plumbing Codes

Interactive HTML reference for commercial kitchen drainage systems, grease interceptors, FOG programs, and fixture rules across multiple states (MN, WI, IA, CO, etc.) with local jurisdictions.

Branded for **Riverview Plumbing**.

Includes diagrams for Minnesota commercial dishwasher setups (direct, indirect receptor, indirect standpipe, DLI).

Open `commercial_kitchen_codes.html` in a browser to explore.

## Files
- `commercial_kitchen_codes.html` — Main interactive reference (with Riverview Plumbing logo)
- `mn-*.png` — MN dishwasher plumbing diagrams
